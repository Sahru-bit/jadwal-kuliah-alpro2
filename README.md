# Jadwal Kuliah ALPRO 2

## Deskripsi
Program untuk mengecek jadwal kuliah berdasarkan hari dan jam serta menampilkan seluruh jadwal pada hari tertentu.

## Fitur
- Cek kuliah yang sedang berlangsung
- Menampilkan seluruh jadwal pada hari tertentu
- Menggunakan Sequential Search
- Menggunakan Struct dan Array

## Bahasa Pemrograman
Go (Golang)
